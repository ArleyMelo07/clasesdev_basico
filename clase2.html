🧩 Parte 1 — Lógica de programación

¿Qué es la lógica de programación?

La lógica de programación es la capacidad de crear pasos organizados y coherentes para resolver un problema. Antes de escribir código, todo programador debe pensar en la secuencia de acciones necesarias para llegar al resultado deseado.

Analogía: Un algoritmo es como una receta de cocina: si faltan pasos o el orden está mal, el resultado no será el esperado.

Componentes del pensamiento algorítmico

  1. Entrada: los datos que recibe el programa (por ejemplo, números o texto).
  2. Proceso: las operaciones que realiza el programa (sumar, comparar, transformar, etc.).
  3. Salida: el resultado final (por ejemplo, mostrar un mensaje o guardar un archivo).

Diagramas de flujo

Los diagramas de flujo te ayudan a visualizar la secuencia de pasos de un algoritmo. Cada figura tiene un significado:

  • Óvalo: inicio o fin.
  • Rectángulo: proceso.
  • Rombo: decisión (sí/no).
  • Flechas: dirección del flujo.

Pseudocódigo

El pseudocódigo es una forma de escribir los pasos de un algoritmo sin usar un lenguaje real de programación. Sirve para planificar lo que luego se convertirá en código. 

INICIO
  leer nota1
  leer nota2
  leer nota3
  suma = nota1 + nota2 + nota3
  promedio = suma / 3
  mostrar promedio
FIN

Actividad práctica

Escribe en tu cuaderno el pseudocódigo para preparar un sándwich. Luego revisa tus pasos y verifica si tu “programa” funcionaría sin errores.

🧍 Actividad 1 — Presentación en Python

Ahora escribirás tu primer programa interactivo usando Python. El objetivo es practicar la función input() para recibir datos del usuario y print() para mostrarlos en pantalla. 

# Programa de presentación
nombre = input("¿Cuál es tu nombre? ")
edad = input("¿Cuántos años tienes? ")
ciudad = input("¿De dónde eres? ")

print("----- Presentación -----")
print("Nombre:", nombre)
print("Edad:", edad)
print("Ciudad:", ciudad)
print("------------------------")

Explicación paso a paso:

  1. input(): espera que el usuario escriba algo; siempre devuelve texto (str).
  2. Asignación: el valor que introduces se guarda en una variable (por ejemplo, nombre).
  3. print(): muestra texto o variables en pantalla.
  4. El programa se ejecuta línea por línea, de arriba hacia abajo.

💡 Prueba agregando un dato adicional, como tu materia favorita, y muestra todo en una sola línea formateada.

💾 Parte 2 — Variables y memoria

¿Qué es una variable?

Una variable es un nombre que se usa para guardar información temporal en la memoria del computador. Imagina una caja con etiqueta: la etiqueta es el nombre de la variable y el contenido es su valor.

En Python no necesitas declarar el tipo de dato: el lenguaje lo detecta automáticamente cuando asignas un valor.

Operadores de asignación (detallado)

El operador de asignación básico es =, que guarda un valor en una variable. Además existen operadores de asignación compuesta (o aumentada) que combinan una operación y asignación en una sola instrucción.

Asignación básica

a = 5       # a vale 5
b = a       # b ahora referencia el mismo valor que a (5)

Aquí b recibe el valor actual de a. Si luego cambias a, b no cambia automáticamente: 

a = 5
b = a
a = 7
print(a)  # 7
print(b)  # 5

Asignación aumentada (operadores compuestos)

Estos operadores son equivalentes a aplicar una operación sobre la variable y reasignarla:

  • += → suma y asigna (x += 2 es lo mismo que x = x + 2).
  • -= → resta y asigna.
  • *= → multiplica y asigna.
  • /= → divide y asigna (produce float si corresponde).
  • %= → módulo y asigna (resto de la división).
  • //= → división entera y asigna.
  • **= → potencia y asigna.
x = 10
x += 5    # x ahora vale 15
x *= 2    # x ahora vale 30
x -= 4    # x ahora vale 26

Asignación múltiple y encadenada

Puedes asignar varios valores en una sola línea:

a, b, c = 1, 2, 3
# o asignar el mismo valor a varias variables
x = y = z = 0

Intercambiar valores (swap)

En Python puedes intercambiar dos variables sin usar una variable temporal:

a = 5
b = 10
a, b = b, a
# ahora a == 10 y b == 5

Direcciones de memoria y id()

Todo valor se guarda en una dirección de memoria. Las variables apuntan a esa dirección. Puedes verlo con la función id(): 

x = 10
print("Valor:", x)
print("id(x):", id(x))

Si cambias el valor, Python crea una nueva referencia de memoria.

Modificar variables

contador = 1
contador = contador + 1   # ahora contador vale 2
contador += 1             # forma abreviada: ahora vale 3

Tipos de datos (con ejemplos)

  • int — enteros: 5, -3, 0
  • float — decimales: 3.14, -0.5
  • str — texto: "Hola", 'Mundo'
  • bool — booleanos: True, False
  • list — listas: [1,2,3]
  • dict — diccionarios: {"nombre":"Ana"}

Conversión de tipos

Cuando usas input(), los valores ingresados se guardan como texto (str). Para trabajar con números, debes convertirlos: 

a = input("Número A: ")     # '12' (str)
b = input("Número B: ")     # '3'  (str)
a = int(a)
b = int(b)
print("Suma:", a + b)

Errores comunes

  • Intentar sumar texto sin convertirlo a número.
  • Usar una variable que no fue creada (NameError).
  • Confundir = (asignación) con == (comparación).

Buenas prácticas

  1. Usa nombres descriptivos: nota_final en lugar de n.
  2. Usa snake_case (ejemplo: mi_variable).
  3. No uses una variable para más de una función.
  4. Evita variables globales innecesarias.
  5. Comenta cuando el propósito no sea obvio.

Gestión de memoria

Python administra automáticamente la memoria con un recolector de basura. Cuando una variable deja de usarse, su espacio se libera automáticamente.

Ejercicio: calculadora simple

Crea un programa que pida dos números y calcule la suma, resta, multiplicación y división: 

a = int(input("Número 1: "))
b = int(input("Número 2: "))

print("Suma:", a + b)
print("Resta:", a - b)
print("Producto:", a * b)
print("División:", a / b)
