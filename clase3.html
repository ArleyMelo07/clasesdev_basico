💾 Parte 1 — Repaso de Variables

Recordemos que una variable es un espacio en la memoria donde se guarda información que puede cambiar mientras el programa se ejecuta.

🧠 Una buena práctica es usar nombres descriptivos y en minúsculas, separados por guiones bajos (_). 
# Ejemplo básico
nombre = "Carlos"
edad = 20
promedio = 4.5

print("Nombre:", nombre)
print("Edad:", edad)
print("Promedio:", promedio)

En este ejemplo, cada variable tiene un tipo de dato diferente: str (texto), int (entero) y float (decimal).

🔢 Parte 2 — Tipos de datos en Python

Python tiene varios tipos de datos básicos. Estos son los más usados:

  • int: números enteros (10, -5, 0)
  • float: números con decimales (3.14, -2.5)
  • str: texto ("Hola", 'Python')
  • bool: valores lógicos (True, False)

Para saber el tipo de dato de una variable puedes usar la función type():

a = 10
b = 3.5
c = "Hola"
d = True

print(type(a))  # 
print(type(b))  # 
print(type(c))  # 
print(type(d))  #
📝 Consejo: antes de operar con una variable, asegúrate de conocer su tipo. Esto evitará muchos errores.

🧮 Parte 3 — Asignaciones y conversiones

Asignación básica

x = 5
y = 10
resultado = x + y
print("El resultado es:", resultado)

Asignación múltiple

Permite declarar varias variables en una sola línea:

nombre, edad, ciudad = "Ana", 18, "Medellín"
print(nombre, edad, ciudad)

Conversión de tipos

Cuando se usan datos ingresados por teclado, es común convertirlos a número para hacer operaciones:

numero1 = int(input("Ingresa un número: "))
numero2 = float(input("Ingresa otro número: "))
print("La suma es:", numero1 + numero2)
🔄 Recuerda: int() convierte texto a número entero, float() a decimal y str() a texto.

🧠 Parte 4 — Buenas prácticas al usar variables

  • Usa nombres descriptivos: nota_final es mejor que n.
  • No empieces nombres con números ni uses espacios (usa guion bajo).
  • Evita cambiar el tipo de una variable a menos que sea necesario.
  • Comenta el código cuando sea útil para recordar su propósito.
  • Evita escribir todo en una sola línea. La claridad es más importante que la rapidez.
💡 Consejo: Escribe tu código pensando en que otra persona (o tú mismo en el futuro) deba entenderlo fácilmente.

🧩 Parte 5 — Ejercicios de repaso

  1. Crea un programa que pida tu nombre, edad y ciudad, y los muestre en una sola línea formateada.
  2. Declara tres variables numéricas y calcula su promedio.
  3. Convierte un número decimal a entero usando int() y observa qué ocurre.
  4. Escribe un programa que cambie los valores de dos variables (intercambio).
  5. Investiga qué ocurre si sumas texto y números. ¿Por qué sucede?
🧩 Practica estos ejercicios hasta que puedas resolverlos sin mirar el ejemplo. La práctica crea confianza.
