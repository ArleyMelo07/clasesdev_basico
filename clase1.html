Clase 1: Introducción a la Programación

Duración: 1 hora y 30 minutos

1. Bienvenida

Bienvenidos al fascinante mundo de la programación. A lo largo de este curso aprenderemos a comunicarnos con las computadoras, entendiendo cómo piensan y cómo podemos darles instrucciones paso a paso para resolver problemas.

2. ¿Qué es la programación?

La programación es el proceso de crear un conjunto de instrucciones que le dicen a una computadora cómo realizar una tarea. Es el lenguaje con el que los humanos le hablamos a las máquinas.

Podemos comparar programar con dar una receta: si seguimos los pasos correctamente, obtendremos el resultado deseado.

3. ¿Qué es un algoritmo?

Un algoritmo es una secuencia ordenada de pasos que permiten resolver un problema o realizar una tarea. Es la base de toda programación.

Por ejemplo, un algoritmo para preparar un sándwich sería:

  1. Tomar el pan
  2. Agregar los ingredientes
  3. Tapar con otra rebanada
  4. Servir

4. ¿Qué es un lenguaje de programación?

Un lenguaje de programación es un sistema de comunicación estructurado que permite escribir instrucciones que una computadora puede entender y ejecutar. Existen muchos lenguajes, cada uno con su propósito.

  • Python: fácil de aprender y muy usado en inteligencia artificial, ciencia de datos y automatización.
  • Java: poderoso y versátil, usado para aplicaciones empresariales y móviles (Android).
  • PHP: enfocado en el desarrollo web, especialmente en el lado del servidor.

5. Instalación de herramientas

5.1. Visual Studio Code

Visual Studio Code (VS Code) será nuestro editor de código. Es donde escribiremos y ejecutaremos nuestros programas.

  1. Ir a code.visualstudio.com
  2. Descargar según el sistema operativo
  3. Instalar y abrir
  4. Instalar la extensión “Code Runner”

5.2. Instalar Python

Python es un lenguaje interpretado. Necesitamos su intérprete para que el sistema pueda ejecutar el código.

  1. Descargar desde python.org
  2. Seleccionar “Add Python to PATH” durante la instalación
  3. Verificar escribiendo en la terminal: python --version

5.3. Instalar Java JDK

Para ejecutar Java necesitamos el JDK (Java Development Kit), que incluye herramientas para compilar y ejecutar código Java.

  1. Descargar desde Oracle
  2. Instalar y agregar la variable de entorno JAVA_HOME
  3. Verificar escribiendo en la terminal: java -version y javac -version

5.4. Instalar PHP

PHP necesita un intérprete para ejecutarse. Podemos usar XAMPP, que incluye Apache (servidor web) y PHP.

  1. Descargar desde apachefriends.org
  2. Instalar y ejecutar Apache
  3. Verificar escribiendo en la terminal: php -v

6. Nuestro primer programa: ¡Hola Mundo!

6.1. En Python

print("¡Hola, mundo!")

La función print() muestra en pantalla el texto entre comillas. Se ejecuta con Ctrl + Alt + N si tienes Code Runner.

6.2. En Java

public class HolaMundo {
  public static void main(String[] args) {
    System.out.println("¡Hola, mundo!");
  }
}

En Java todo programa debe tener una clase. System.out.println() imprime texto en la consola. Para ejecutarlo:

  1. Guarda como HolaMundo.java
  2. Compila con: javac HolaMundo.java
  3. Ejecuta con: java HolaMundo

6.3. En PHP

<?php
  echo "¡Hola, mundo!";
?>

En PHP usamos echo para mostrar texto. Guarda el archivo como hola.php en la carpeta htdocs de XAMPP. Luego abre en el navegador http://localhost/hola.php.

7. Nuestro primer programa: ¡Hola Mundo en HTML!

HTML

<!DOCTYPE html>
<html>
  <head>
    <title>Hola Mundo</title>
  </head>
  <body>
    <h1>¡Hola, mundo!</h1>
  </body>
</html>

El código HTML es utilizado para estructurar contenido en la web. En este caso:

  • <!DOCTYPE html>: Declara que este archivo es HTML5.
  • <html>: Es el contenedor de toda la página.
  • <head>: Contiene metadatos, como el título de la página.
  • <body>: Contiene el contenido visible, en este caso un título.

Para visualizar este archivo en el navegador:

  1. Crea un archivo llamado index.html.
  2. Pega el código anterior dentro del archivo.
  3. Abre el archivo en cualquier navegador y verás el mensaje “¡Hola, mundo!” en pantalla.

8. Cierre y tarea

Hoy aprendimos qué es la programación, los algoritmos, los lenguajes y cómo crear nuestro primer programa en diferentes lenguajes. La tarea es practicar los tres “Hola Mundo” y escribir un pequeño algoritmo en papel que describa una tarea diaria paso a paso.
